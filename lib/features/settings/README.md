# features/settings/

The settings screen (profile, account details, current wallet data, appearance, sign-out) and the saved theme mode.

| Folder | Purpose |
|---|---|
| `domain/` | `ThemePreference` and the `SettingsRepository` interface. |
| `data/` | Saves the preference in `shared_preferences`. |
| `presentation/` | `ThemeBloc`, `SettingsPage` and its section widgets. |
